# Security Policy

## Supported Versions

Only the default branch is maintained. This is a static site; there are no releases.

## Reporting a Vulnerability

Please **do not** open a public issue for a security problem.

Use GitHub's private vulnerability reporting instead:

https://github.com/rngfbbbffhjgggd-commits/rngfbbbffhjgggd-commits.github.io/security/advisories/new

The report stays private between you and the maintainer until a fix is published. This is a personal project, so there is no SLA and no paid support.

## Scope

This is a static portfolio site served by GitHub Pages.

In scope:
- cross-site scripting or content injection in the page
- links or embedded resources pointing at compromised destinations

Out of scope:
- anything in GitHub Pages itself (report that to GitHub)
- the security posture of third-party sites this page links to

## What helps a report

- the page and the exact string or element involved
- how it can be triggered in a browser
- the impact you believe it has
